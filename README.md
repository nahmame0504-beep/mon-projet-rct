#  TP 4 : Ma To-Do List Interactive (React)

Ce projet est une application web interactive de gestion de tâches développée avec **React**, réalisée dans le cadre du TP 4 de synthèse.

##  Fonctionnalités

-  **Ajout de tâches** : Ajout dynamique via un formulaire contrôlé.
-  **Gestion de l'état** : Possibilité de cocher/décocher une tâche pour la marquer comme terminée (texte barré).
-  **Suppression** : Bouton pour retirer définitivement une tâche de la liste.
-  **Affichage dynamique** : Utilisation du hook `useState` pour la mise à jour en temps réel.

##  Technologies utilisées

- **React** (Composants fonctionnels, Hooks `useState`)
- **JavaScript (ES6+)**
- **CSS3** (Style personnalisable)

##  Structure du projet

```text
src/
├── components/
│   ├── TodoForm.js      # Formulaire de saisie
│   ├── TodoItem.js      # Affichage d'une ligne de tâche
│   └── TodoList.js      # Liste globale des tâches
├── App.js               # Composant racine (State principal)
├── App.css              # Feuille de style
└── index.js             # Point d'entrée de l'application
```
